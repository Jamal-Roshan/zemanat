# سامانه‌ی صدور ضمانت‌نامه و گواهی (Zemanat)

بازطراحی سامانه‌ی قدیمی «ضمانت‌نامه و گواهی» با Blazor Server روی .NET 10، EF Core و SQL Server (۲۰۱۶ به بالا).
رابط کاربری کاملاً فارسی، راست‌به‌چپ، با تاریخ شمسی و ارقام فارسی است و بدون نیاز به اینترنت اجرا می‌شود.

> پروژه مرحله‌به‌مرحله ساخته می‌شود. هر مرحله روی شاخه‌ی `main` می‌آید.

## وضعیت مراحل

| مرحله | محتوا | وضعیت |
|---|---|---|
| ۱ | اسکلت پروژه، CI، فونت Vazir، ابزارهای فارسی (تاریخ شمسی، مبلغ به حروف، سقف اعتبار، شماره‌ی سند، کد پیگیری) همراه با تست | انجام شد |
| ۲ | مدل داده، EF Core، Identity، نقش‌ها، تنظیمات، کاربر `admin`، مایگریشن | انجام شد |
| ۳ | ورود، بارگذاری اکسل پرسنل، مدیریت کاربران و نقش‌ها | انجام شد |
| ۴ | ثبت درخواست، سقف و مازاد، تأیید، شماره‌گذاری | انجام شد |
| ۵ | قالب‌های چاپ، QR، صفحه‌ی اصالت‌سنجی، استعلام بانکی | بعدی |
| ۶ | تسویه و ابطال، گزارش‌ها و داشبورد، لاگ ممیزی | |
| ۷ | داده‌ی نمونه، پاک‌سازی سامانه، راهنمای نصب IIS، انتقال داده‌ی قدیمی | |

## ساختار

```
src/Zemanat.Core   منطق خالص و بدون وابستگی (تاریخ، متن فارسی، پول، قاعده‌ی اعتبار)
src/Zemanat.Data   دسترسی به داده (EF Core) - از مرحله ۲
src/Zemanat.Web    برنامه‌ی Blazor Server
tests/Zemanat.Tests تست‌های واحد (xUnit)
```

## اجرا روی کامپیوتر

پیش‌نیاز: .NET 10 SDK.

```bash
dotnet test Zemanat.sln
dotnet run --project src/Zemanat.Web
```

آدرس برنامه: <http://localhost:5080>

### یک‌بار: دریافت Bootstrap و آیکون‌ها

برای اینکه سایت کاملاً آفلاین باشد، Bootstrap 5 (RTL) و Bootstrap Icons داخل مخزن نگه‌داری می‌شوند.
در گیت‌هاب به تب **Actions** بروید، workflow با نام **Vendor front-end assets** را انتخاب کنید و **Run workflow** را بزنید.
بعد از پایان، `git pull` کنید.

## CI

با هر push روی `main` پروژه بیلد و تست می‌شود و خروجی publish به‌عنوان artifact (`zemanat-web`) ذخیره می‌شود.

## تنظیمات مهم

- رشته‌ی اتصال دیتابیس فقط از متغیر محیطی `ZEMANAT_CONNECTION_STRING` خوانده می‌شود (از مرحله‌ی ۲). هیچ‌وقت داخل مخزن نگذارید.
- مبالغ در دیتابیس به ریال ذخیره می‌شوند و واحد نمایش (ریال یا تومان) از تنظیمات مدیریت تعیین می‌شود.

## فونت

فونت Vazir (نسخه‌ی ارقام فارسی) با مجوز آزاد در `wwwroot/fonts/vazir` همراه پروژه است.
